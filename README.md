#  PustakBhandar

A modern frontend-only online bookstore built using React.js and Bootstrap 5. The project provides a clean, responsive, and user-friendly interface for browsing books, managing a shopping cart, and maintaining a wishlist.

## Live Demo

🔗 https://pustak-bhandar.vercel.app

## Features

- 🏠 Responsive Home Page
- 📖 Browse Books
- 🔍 Search Books
- ❤️ Wishlist
- 🛒 Shopping Cart
- 📄 Book Details Page
- 👤 User Profile
- 📱 Fully Responsive Design

## Tech Stack

- React.js
- Bootstrap 5
- React Router DOM
- Context API
- JavaScript (ES6)
- HTML5
- CSS3
- React Icons

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/pustak-bhandar.git
```

2. Navigate to the project folder

```bash
cd pustak-bhandar
```

3. Install dependencies

```bash
npm install
```

4. Start the development server

```bash
npm start
```
